# 🩸 Blood Bank Website

A secure, user-friendly web platform designed to manage blood donation and distribution efficiently. It acts as a bridge between donors, patients, hospitals, and blood banks — ensuring timely availability of blood during emergencies.

## 📖 About

Blood shortages during emergencies can cost lives. This project aims to simplify the process of finding donors, registering as a donor, and connecting patients/hospitals with available blood banks through a simple, accessible website.

## ✨ Features

- 🏠 **Home / Front Page** — Landing page introducing the platform
- 📝 **Registration Form** — Donors can register their details
- ℹ️ **About Us Page** — Information about the initiative and its mission
- 🎨 Clean, responsive UI built with HTML, CSS, and JavaScript

## 🛠️ Tech Stack

- **HTML5** — Page structure
- **CSS3** — Styling and layout
- **JavaScript** — Interactivity

## 🚀 Getting Started

### Prerequisites

You just need a modern web browser. No backend setup is required to view the static pages.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/SanjayNivasG/Blood-Bank-website.git
   ```
2. Navigate into the project folder
   ```bash
   cd Blood-Bank-website
   ```
3. Open `frontpage.html` in your browser to launch the site
   ```bash
   # On most systems, you can just double-click frontpage.html
   # or run:
   open frontpage.html      # macOS
   start frontpage.html     # Windows
   xdg-open frontpage.html  # Linux
   ```

## 🖥️ Usage

- Visit the **Front Page** to explore the platform
- Go to **Register** to sign up as a blood donor
- Check the **About Us** page to learn more about the initiative
